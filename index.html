Before we begin

Let’s create a clean test setup.

This helps us tell whether the problem is caused by the machine, its setup, or the materials.

  1. Remove any specialty presser foot and install the standard zigzag or all-purpose foot.
  2. Set the machine to a basic straight stitch with a medium stitch length.
  3. Use two layers of ordinary woven cotton fabric.
  4. Use regular all-purpose sewing thread in both the needle and bobbin.
